🥗 NutriDB – Desain UI/UX

Aplikasi pencari gizi makanan dengan filter alergen dan pencatat makan. Mobile-first, bahasa Indonesia. Data pada layar hanya contoh.

1. Alur pengguna

Atur alergen (sekali)→Cari makanan→Lihat detail gizi→Tambah ke makan→Pantau total harian

2. Design system

Warna
Hijau utama #2F7D4F
Hijau muda #E6F2EA
Alergen #C0392B
Sedang #E0A030
Latar #F4F1EA
Tipografi
  • Font sistem (cepat, jelas di semua HP)
  • Judul 18–26 px tebal, isi 13–15 px
  • Angka gizi dibuat tebal agar mudah dipindai
Prinsip UX
  • Alergen = merah, selalu terlihat, tidak hanya warna (ada ikon ⚠ dan teks)
  • Satu aksi utama per layar
  • Tombol minimal 44 px (mudah disentuh)
  • Mendukung mode gelap
